## About me

I'm Trung, a mobile developer based in Da Nang and a Software Engineering graduate of the University of Science and Technology, The University of Danang. I spend most of my time inside Xcode building native iOS apps, and the rest shipping cross-platform products.

- **Native iOS** with Swift, SwiftUI and UIKit, from networking layers to Core Data persistence.
- **Cross-platform** work with Flutter (Clean Architecture, Bloc) and React Native (Redux Toolkit).
- **Android** background in Java and Kotlin, plus Firebase across the stack.
- **Digging into right now:** Swift Concurrency & Combine, Core Data, profiling with Instruments, and going deeper on UIKit.
